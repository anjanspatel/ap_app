Frequently Asked

RX gaskets (e.g. RX-35) are pressure-energized and self-seating — internal pressure improves the seal. BX gaskets (e.g. BX-154) are used for 10K psi and above; their grooves have a different geometry that provides additional seating load. BX gaskets require BX ring grooves and cannot be interchanged with RX grooves. For 3K–5K service, RX is standard; for 10K–15K, BX is required per API 6A.
Yes. API 6A allows using a higher-rated flange at lower working pressure, provided the ring gasket type and groove geometry are compatible. A 5K flange at 3K service is common for future proofing or interchangeability. The bolt torque should be calculated based on the actual working pressure, not the flange rating.
API 6A requires ASTM A193 B7 (chrome-moly alloy, Sy=105 ksi for ≤1" dia.) for standard sour service flanges. Low-temperature service (below −45°C) requires A193 L7. Hydrogen sulphide (H₂S) sour service may require A193 B7M per NACE MR0175 / ISO 15156. Always confirm with your project specification and EPC.
These dimensions are from API Specification 6A / ISO 10423, which governs wellhead and christmas tree equipment. API 6A flanges have higher pressure ratings and different bolt patterns than ASME B16.5 flanges of the same nominal size. They are not interchangeable. API 6A uses a ring joint (RTJ) groove, while ASME B16.5 can be raised face (RF), flat face (FF), or RTJ.
The bore (B) is the minimum inner diameter through the flange. It must be equal to or larger than the connecting pipe bore to prevent flow restriction. The nominal pipe size (NPS) in the flange designation refers to the approximate bore, not an exact number. The actual bore shown here is the minimum full-bore dimension per API 6A Table 2.
